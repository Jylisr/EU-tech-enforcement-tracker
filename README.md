# EU Tech Enforcement Tracker

A structured dataset and analysis of GDPR enforcement decisions across EU
Member States, examining how Article 82 non-material damages awards vary
across jurisdictions.

## Purpose

This project tracks enforcement decisions in EU digital regulation
(primarily GDPR) across five Member States and several digital sectors, to
examine whether enforcement outcomes — particularly damages awards under
Article 82 — are consistent across jurisdictions.

## Research Question

To what extent do procedural and institutional differences across Member
States produce divergent enforcement outcomes under EU digital regulation?

## Variables

See `docs/coding_rules.md` for full definitions. Summary:

| Variable | Description |
|---|---|
| `case_id` | Unique identifier |
| `member_state` | EU Member State where decision was issued |
| `authority` | Specific DPA or court |
| `year` | Year of decision |
| `sector` | Digital sector (social_media, adtech, ecommerce, etc.) |
| `legal_basis` | Primary GDPR article invoked |
| `violation_type` | Category of violation |
| `enforcing_body` | DPA or court |
| `damages_awarded` | Compensation awarded to data subject (EUR), if any |
| `harm_type` | Type of harm (non-material, material, reputational, ...) |
| `cross_border` | Whether case involved cross-border processing |

## Methodology

Cases are drawn from GDPRhub, national DPA decision registers, and the
EDPB decision register, and coded against explicit rules recorded in
`docs/coding_rules.md`. Every judgment call made during coding is logged in
`docs/coding_log.md` as it happens, which becomes the basis for the paper's
methodology section.

## Dependencies

- R (>= 4.1)
- `tidyverse`
- `ggplot2` (included in tidyverse)

Install with:

```r
install.packages("tidyverse")
```

Run the analysis from the repo root:

```r
source("analysis/enforcement_analysis.R")
```

## Status

Active data collection — see `docs/coding_log.md` for progress. Once at
least 30 cases are coded, `analysis/enforcement_analysis.R` produces the
descriptive tables and figures underlying the accompanying SSRN working
paper (draft in `paper/`).
